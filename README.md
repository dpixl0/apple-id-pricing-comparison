**未激活 iCloud 和已激活 iCloud。** 未激活的号只能登 App Store 下应用，进不了“设置”里的 Apple ID 入口，也开不了 iCloud 备份和“查找我的 iPhone”。功能少，但安全性高：账号真出问题，锁不到你的设备。已激活的功能完整，代价是一旦账号异常，你的设备可能被牵连。只下载应用的话，未激活完全够用。
